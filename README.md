# QazaqHub

QazaqHub — Қазақстанға арналған мобильді суперқосымша интерфейсінің бастапқы нұсқасы.

## Технологиялар
- React
- Vite
- Mobile-first CSS

## Жергілікті іске қосу
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Cloudflare Pages
- Build command: `npm run build`
- Build output directory: `dist`

## Қазіргі мүмкіндіктер
- Қара-күлгін мобильді интерфейс
- Басты бет, маркет, қызметтер және таңдаулылар
- Хабарландыруларды іздеу
- Таңдаулыларға қосу/алып тастау
- Жарияланым қосу формасы
- Телефонға бейімделген төменгі навигация

Ескерту: әзірге тауарлар демо-деректер және жарияланымдар сессия ішінде сақталады. Firebase авторизациясы, Firestore және нақты уақыттағы чат келесі кезеңде қосылады.
